# Покрокова інструкція — лабораторна №4 (цифра «8», група КІ-408)

**📸** — скріншот для звіту, зберігати в `docs/img/` під указаною назвою.

## Параметри моделі

| Параметр | Значення |
|---|---|
| Цифра | 8 (КІ-40**8**) |
| Габарит | 100 × 140 мм, товщина **10 мм** |
| Шрифт | Arial Bold, висота великих літер 8 мм |
| **БАРТОШКО** (прізвище) | верхня перемичка, центр (50; 130) — **опуклий**, +2 мм над верхньою гранню |
| **ОЛЕКСАНДР** (ім'я) | середня перемичка, центр (50; 71) — **увігнутий**, глибина 1.5 мм |
| **ІГОРОВИЧ** (по батькові) | нижня перемичка, центр (50; 10) — **наскрізний**, виріз 12 мм > 10 мм |

Файли (генеруються `python3 gen_dxf.py`):
- `dxf/digit8_only.dxf` — лише контур цифри (шари `DIGIT_OUTER`, `DIGIT_HOLES`);
- `dxf/digit8_full.dxf` — цифра + контури тексту, кожен напис на шарах `*_OUTER` (зовнішні контури літер) і `*_HOLES` (внутрішні «дірки» літер О, Р, А, Б, Д, В).

> Чому DXF для тексту в AutoCAD: звичайний TEXT/MTEXT не можна екструдувати — спершу його треба перетворити на контури (`TXTEXP` з Express Tools, яких немає в AutoCAD for Mac). Тому контури літер уже підготовлені в DXF. Якщо у тебе AutoCAD під Windows — можна й так: `TEXT` → `TXTEXP` → `REGION`, решта кроків та сама.

## Етап 1. AutoCAD

1. **Відкрити** `dxf/digit8_full.dxf` (одиниці — міліметри: `UNITS` → Insertion scale = Millimeters).
2. **2D → REGION.** Команда `REGION`, виділити все (`ALL`), Enter. AutoCAD повідомить «42 regions created».
   📸 `acad_2d.png` — 2D-контур із регіонами.
3. Перейти в 3D: робочий простір **3D Modeling**, вид `-VIEWPOINT` / *SW Isometric*, стиль *Shaded* або *Realistic*.
4. **Тіло цифри.**
   - `LAYISO` → шари `DIGIT_OUTER` і `DIGIT_HOLES`.
   - `EXTRUDE` → вибрати 3 регіони → висота **10**.
   - `SUBTRACT` → вибрати зовнішнє тіло, Enter → два тіла вікон, Enter.
   - `LAYUNISO`.
5. **Прізвище — опуклий текст (UNION).**
   - `LAYISO` → `SURNAME_OUTER`, `SURNAME_HOLES`.
   - `MOVE` → вибрати всі регіони прізвища → base point `0,0,0` → displacement `0,0,10` (на верхню грань).
   - `EXTRUDE` → усі регіони прізвища → висота **2**.
   - `SUBTRACT`: спочатку тіла `SURNAME_OUTER` (літери), Enter, потім тіла `SURNAME_HOLES`, Enter. Так у літерах з'являються «дірки».
   - `LAYUNISO`.
   - `UNION` → цифра + усі літери прізвища.
6. **Ім'я — увігнутий текст (SUBTRACT).**
   - Регіони `NAME_*`: `MOVE` на `0,0,10`.
   - `EXTRUDE` висота **-1.5** (вниз у тіло).
   - `SUBTRACT`: літери мінус їхні дірки.
   - `SUBTRACT`: цифра, Enter, потім усі літери імені, Enter.
7. **По батькові — наскрізний текст (SUBTRACT).**
   - Регіони `PATRONYMIC_*`: `MOVE` на `0,0,-1`.
   - `EXTRUDE` висота **12** (з −1 до 11 мм, тобто довше за товщину 10 мм).
   - `SUBTRACT`: літери мінус дірки.
   - `SUBTRACT`: цифра мінус літери.

   ⚠️ Внутрішні острівці літер «О», «Р», «В» при наскрізному вирізі випадуть. Це очікувана особливість наскрізного контуру (на трафаретах тому роблять перемички), її варто згадати у звіті.
8. Перевірка: `MASSPROP` → об'єм ≈ **81 000 мм³** (контрольне значення з `gen_dxf.py`).
   📸 `acad_3d.png` — фінальна модель (ізометрія, Realistic).
9. **Експорт STL.**
   - Команда `STLOUT` (або *File → Export → Other formats → .stl*) → вибрати тіло → Binary = Yes → `stl/digit8_autocad.stl`.
   - STLOUT вимагає, щоб тіло лежало в додатному октанті. У нас Z від 0 до 12, X/Y від 0, тож усе гаразд.

## Етап 2. Fusion 360

1. **New Design**, одиниці **mm**. Browser → правий клік на root → **New Component** `Digit8`, зробити активним.
2. **Create Sketch** на площині XY.
   - Варіант А: *Insert → Insert DXF* → `dxf/digit8_only.dxf`.
   - Варіант Б: намалювати самому. Нижнє кільце — прямокутник 0..100 × 0..80 з *Fillet* R24. Верхнє — 6..94 × 60..140, R22. Вікна: 18..82 × 20..58 (R8) і 22..78 × 84..120 (R8).

   *Finish Sketch*.
3. **Extrude** профілю цифри → Distance **10 mm**, Operation **New Body**.
4. **Create Sketch** на верхній грані цифри → **Create → Text**. Для кожного напису:
   - шрифт **Arial**, Bold, висота **8 mm**, вирівнювання по центру;
   - вставити в точки (50;130), (50;71), (50;10): БАРТОШКО, ОЛЕКСАНДР, ІГОРОВИЧ.

   *Finish Sketch*.
5. **Extrude** напису БАРТОШКО → **2 mm**, Operation **Join**.
6. **Extrude** напису ОЛЕКСАНДР → **−1.5 mm**, Operation **Cut**.
7. **Extrude** напису ІГОРОВИЧ → Extent **All** (або −12 mm), Operation **Cut**.

   Якщо ескіз сховався після попереднього Extrude, увімкнути його «оком» у Browser.

   📸 `fusion_model.png` — модель і **Timeline** унизу (видно Extrude Join / Cut / Cut).
8. **Експорт:** Browser → правий клік на Body → **Save As Mesh** → Format STL (Binary), Units mm → `stl/digit8_fusion.stl`.

## Етап 3. Ultimaker Cura

1. Встановити Ultimaker Cura 5.x. Принтер, наприклад, **Creality Ender-3 V2** (стіл 220×220 мм, модель 100×140 вміщується) або Ultimaker S3. Матеріал — Generic PLA.
2. **Open** `stl/digit8_fusion.stl`. Модель лежить пласко: опуклий текст угорі, на стіл лягає нижня грань.
3. *Print settings → Custom*:
   - **Layer Height 0.2 mm**;
   - **Infill Density 20 %**;
   - **Support:** вимкнено. Нависань немає: увігнутий і наскрізний текст — це вертикальні стінки, опуклий текст стоїть на верхній грані. У звіті це треба обґрунтувати; можна для порівняння показати *Support on*, Cura нічого не згенерує.
   - **Build Plate Adhesion: Brim**.
4. **Slice**. Записати **час друку** і **масу/довжину філаменту** (кнопка деталей унизу праворуч).
   📸 `cura_settings.png` — панель налаштувань + підсумок (час, грами).
5. **Preview** → повзунок шарів. Подивитись і за бажанням зняти 📸 `cura_layers.png`:
   - шар ~1 мм: у нижній перемичці видно наскрізні літери ІГОРОВИЧ (порожнини);
   - шар ~9 мм: видно заглиблення ОЛЕКСАНДР;
   - шари 10–12 мм: друкуються лише літери БАРТОШКО.
6. (Опційно) *Save to Disk* → `gcode/digit8.gcode`.
